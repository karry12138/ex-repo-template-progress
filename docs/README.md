# docs/ —— 文档与进展跟踪

本目录承载两类内容：**说明文档**与**带时间戳的进展跟踪**（机制来自 dk-incre）。

## 说明文档

| 文件 | 用途 |
|------|------|
| `REPRODUCE.md` | 最短时间复现指南（命令 + 预期产物） |
| `MANIFEST.md` | 资产清单（已纳入 / 外链 / 入口对照） |

## 🧭 带时间戳的进展跟踪（核心）

| 文件 | 作用 | 更新频率 |
|------|------|------|
| **`PROGRESS.md`** | 当前锚点：我在哪 / 已完成 / 下一步 / 待拍板 | 每次有进展就**覆盖更新** |
| **`logs/YYYYMMDD_HHMMSS_标题.md`** | 时间轴：本次会话做了什么、背景、待办 | 每次有进展就**新增一条** |
| `LOG_CONVENTION.md` | 过程文档约定（命名 / 模板 / 收尾动作） | 固化为规范 |

> 约定：每次推进后更新 `PROGRESS.md` 锚点，并新增一条 `docs/logs/` 时间戳记录。

## md→html 阅读转换

- **执行依据**：`*.md`（可 diff、版本管理）
- **阅读用**：`*.html`（同名同目录，渲染后更易读）

```bash
python tools/md_to_html.py --all-docs   # 刷新 docs/ 下所有 md → html
python tools/md_to_html.py README.md
```

> html 是生成物，不要手工编辑；改 md 后重新生成再一起提交。
